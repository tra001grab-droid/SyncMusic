# Sync Music — ចាក់ចម្រៀង និង YouTube ព្រមគ្នាលើទូរស័ព្ទ Android 2-3 គ្រឿង

## របៀបប្រើ
1. ទូរស័ព្ទទាំងអស់ត្រូវភ្ជាប់ **Wi-Fi តែមួយ** (ឬភ្ជាប់ទៅ Hotspot របស់ទូរស័ព្ទ Host)។
2. ទូរស័ព្ទមួយចុច **"ធ្វើជា Host"**។
3. ទូរស័ព្ទផ្សេងទៀតចុច **"ចូលរួម"** — វាស្វែងរក Host ដោយស្វ័យប្រវត្តិ
   (បើរកមិនឃើញ វាយ IP:port ដែលបង្ហាញលើអេក្រង់ Host)។
4. នៅលើ Host បង្កើត **បញ្ជីបទចម្រៀង (Playlist)**:
   - **➕ បន្ថែមបទចម្រៀងពីទូរស័ព្ទ** — អាចជ្រើសរើសច្រើនបទក្នុងពេលតែមួយ
   - បិទភ្ជាប់ **Link YouTube** ហើយចុច **➕ YouTube** (youtube.com/watch, youtu.be, shorts)
   - **🔍 ស្វែងរកចម្រៀងលើ YouTube** — ស្វែងរកក្នុង app ផ្ទាល់ ចុចលើវីដេអូ វាចាក់លើទូរស័ព្ទទាំងអស់ភ្លាមៗ ហើយនៅតែស្ថិតក្នុងទំព័រស្វែងរក (ចុច ☰ ដើម្បីត្រលប់ទៅបញ្ជី)
   - **Share ពី app YouTube**: ក្នុង YouTube ចុច Share → Sync Music — បទនឹងចូលបញ្ជីភ្លាម
     (បើ app មិនទាន់ជា Host វានឹងក្លាយជា Host ដោយស្វ័យប្រវត្តិ)
5. ចុចលើបទណាមួយក្នុងបញ្ជី ឬចុច ▶ — គ្រប់ទូរស័ព្ទចាប់ផ្ដើមព្រមគ្នា។
   ⏮ ⏭ ប្ដូរបទ · ⏸ ផ្អាក · ចុចយូរលើបទ = លុបចេញពីបញ្ជី។
   ពេលបទមួយចប់ វាចាក់បទបន្ទាប់ដោយស្វ័យប្រវត្តិ។
6. បើលឺមិនទាន់ស៊ីគ្នា ប្ដូររបារ **"កែតម្រូវពេល"** លើ Client (+ = លឿនជាង, − = យឺតជាង)។

## បច្ចេកទេស Sync
- **Clock sync** (ដូច NTP): Client ផ្ញើ PING ទៅ Host ជាប្រចាំ ហើយគណនា offset នៃនាឡិកា
  ដោយយកគំរូដែលមាន round-trip time តិចបំផុត។
- **ប្ដូរបទ**: Host ផ្ញើ `ITEM` (មានលេខ version) → Client រៀបចំបទ ហើយឆ្លើយ `READY`។
  Host រង់ចាំ Client ទាំងអស់រួចរាល់ (យូរបំផុត 10 វិនាទី) ទើបចាប់ផ្ដើម។
- **ចាប់ផ្ដើមតាមពេលកំណត់**: `PLAY <version> <position> <ពេលចាប់ផ្ដើម>`។
- **កែ Drift**: Host ផ្ញើទីតាំងបទរៀងរាល់ 1 វិនាទី។
  - **ឯកសារចម្រៀង**: ខុស > 100ms → លោត; ខុស 15-100ms → ប្ដូរល្បឿនបន្តិច (0.97×–1.03×, សំឡេងមិនប្ដូរ)
  - **YouTube**: ខុស > 250ms → លោត (រង់ចាំ 3 វិនាទីរវាងការលោតនីមួយៗ ឲ្យវា buffer)

## YouTube — អ្វីដែលគួរដឹង
- ទូរស័ព្ទនីមួយៗចាក់ YouTube ដោយខ្លួនឯងតាម **YouTube IFrame player ផ្លូវការ**
  (library `android-youtube-player`)។ App **មិនទាញយក** សំឡេងពី YouTube ទេ
  ដូច្នេះទូរស័ព្ទនីមួយៗត្រូវមាន Internet។
- ភាពស៊ីគ្នាប្រហែល **±250ms** (មិនល្អដូចឯកសារចម្រៀងទេ)
  ព្រោះ YouTube player មិនអាចប្ដូរល្បឿនបន្តិចៗបាន ហើយត្រូវ buffer ពេលលោត។
- **ការផ្សាយពាណិជ្ជកម្ម** អាចលេចឡើងខុសពេលគ្នាលើទូរស័ព្ទនីមួយៗ — sync នឹងកែវិញក្រោយ Ads ចប់។
- វីដេអូខ្លះ ម្ចាស់មិនអនុញ្ញាតឲ្យចាក់ក្នុង app ផ្សេង (embed) — វីដេអូទាំងនោះនឹងមិនចាក់ទេ។
- YouTube ឈប់ចាក់ពេលបិទអេក្រង់ ឬចេញពី app (តាមលក្ខខណ្ឌ YouTube) — App រក្សាអេក្រង់ឲ្យភ្លឺជានិច្ច។

## បិទអេក្រង់
**បទចម្រៀងក្នុងទូរស័ព្ទ** ចាក់បន្ត និងនៅតែ sync ពេលបិទអេក្រង់ (មាន notification "Sync Music" បង្ហាញ)។
បើទូរស័ព្ទនៅតែបញ្ឈប់ app (ជាពិសេស Samsung/Xiaomi): Settings → Apps → Sync Music → Battery → **Unrestricted**។

## Build
បើក folder នេះក្នុង **Android Studio** (Ladybug ឬថ្មីជាងនេះ) → Run ▶
ឬ `./gradlew assembleDebug` → APK នៅ `app/build/outputs/apk/debug/app-debug.apk`។

## ឯកសារសំខាន់
| File | តួនាទី |
|---|---|
| `MainActivity.kt` | UI, Playlist, ការចាក់ និងកែ drift |
| `SyncPlayer.kt` | `LocalPlayer` (ExoPlayer) និង `YouTubeSyncPlayer` (IFrame) |
| `Playlist.kt` | ប្រភេទបទក្នុងបញ្ជី, អាន YouTube ID និងចំណងជើង |
| `SyncServer.kt` | Host: TCP control + ផ្ញើ ITEM/PLAY/PAUSE/POS |
| `SyncClient.kt` | Client: clock sync + ទាញយកបទ |
| `FileHttpServer.kt` | HTTP server តូចសម្រាប់ចែកបទចម្រៀង |
